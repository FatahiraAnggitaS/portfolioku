Compensa lock
Frontend System

Compensa - Salary Prediction Using Linear Regression

A Laravel web application that predicts an employee's monthly base salary from four inputs: knowledge score, technical score, logical score, and years of experience. A scikit-learn Linear Regression model is trained offline in Python and exported as a strict JSON artifact, while Laravel performs request-time inference without running Python, stores each prediction as an immutable record, and flags inputs that fall outside the training range (out-of-distribution). The app also provides a searchable prediction history and a model information page that reads real metadata from the artifact.

PHP 8.4 Laravel 13 Blade Tailwind CSS Vite SQLite Python pandas scikit-learn Pest BCMath
